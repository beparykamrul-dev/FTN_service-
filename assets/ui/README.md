# FTN UI Assets

The generated FTN Core Control Plane visual is part of the design reference for the responsive NOC, Aether-Core, FTNVPN, router health, firmware, DNS mesh, and map-based control panel.

Canonical visual file: `ftn-control-plane-promo.webp`

Use the FTN logo and brand configuration consistently across desktop, mobile, Android TV, and web interfaces. UI layouts must auto-adjust to available viewport size.
